# Giveport

Donation links for people in Uganda and across Africa. Donors abroad pay by card, Apple Pay, Google Pay or crypto through NOWPayments, and the money reaches the recipient's own crypto wallet.

## Run locally

```bash
npm install
cp .env.example .env.local   # optional for now
npm run dev
```

Open http://localhost:3000.
